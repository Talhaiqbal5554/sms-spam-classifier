# SMS Spam Classifier

A machine learning web application that classifies SMS messages as Spam or Not Spam.

## Technologies

- Python
- NLTK
- Scikit-learn
- Streamlit
- TF-IDF
- Machine Learning

## Features

- Text preprocessing
- Tokenization
- Stopword removal
- Stemming
- TF-IDF vectorization
- Spam classification
- Streamlit web interface

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
